## 3. 区域逐项说明

### 3.1 侧边栏
- 248px 固定，`#181935 → #262352` 垂直渐变，底部叠加两枚低透明度圆形光斑。
- 品牌区：40×40 圆角方块 + `Sparkles/BookOpen` 图标、`轻小说管理中心 / LIGHTNOVEL STUDIO` 两行。
- `WORKSPACE` 组：工作台、搜索发现、我的书库、下载任务、书源状态、自动追更、统计分析；`SYSTEM` 组：系统设置、GitHub 项目。
- 选中项：`#6C4AD9 → #8B63F2` 横向渐变 + 紫色外发光 + 白色图标/文字；hover：白 6% 叠加。
- 下载任务右侧显示进行中数量徽标（跟随 Mock 任务实时变化）。
- 底部毛玻璃卡：`backdrop-blur` + 白 5.5% 底 + `Deepseek Harness v1.0` + 黄色 `UI 演示模式`；下方 `DESIGNED FOR DSH · 2026`。
- 移动端：`<lg` 收起为抽屉，汉堡按钮打开，遮罩点击/选择页面后自动关闭。

### 3.2 顶栏
- 76px sticky，白 82% + `backdrop-blur-xl` + 底部 1px 淡紫描边。
- 左：`LIGHTNOVEL`（9.5px、加宽字距）`>` 当前页名；移动端显示汉堡。
- 右：琥珀色胶囊「交互原型 · 非真实数据」（含呼吸圆点）、`查看仓库`（外链图标）、通知铃铛（下拉 3 条活动 + Mock 说明）、`LN` 渐变头像。
- 参考图顶栏没有用户姓名，实现同样只保留头像，避免多余元素。

### 3.3 Hero 搜索横幅
- 淡紫渐变 + 右上 `grid-dots` 点阵遮罩 + 右下圆形柔光，`rounded-[22px]`。
- 文案：`FIND YOUR NEXT STORY`（星芒图标）→ 深色标题「在故事之间，」+ 紫色渐变「找到下一次心动。」→ 说明行 → 胶囊搜索框（白底、内阴影、紫色渐变按钮「探索书籍 →」）。
- 提示行：`ⓘ 交互设计演示，搜索仅过滤样例数据`，右侧为「热门」关键词（需求新增，填满参考图的空白区域）。
- 插画：纯 SVG 双书卡 + 细线圆环 + 花瓣 + 星芒。书卡带文字、渐变、阴影与旋转，整体尺寸约占横幅右侧 420×270，避开搜索区；`<lg` 隐藏，避免与文字重叠。

### 3.4 四入口卡片
- 4 等分、白色卡、`rounded-[18px]`、圆形浅色图标底（紫/蓝/绿/粉四套），标题 13.5px + 说明 11px；hover 抬升并加深描边。
- 分别跳转搜索页、任务页、书库页、书源页。

### 3.5 为你精选
- 5 列封面卡，间距 15px，卡内 6px 白边 + 1px 描边。
- 封面统一 3:4，SVG `slice` 裁切，**不会拉伸**；左上 `LIGHT NOVEL / 01`，底部白色书名 + 英文小注 + 分隔短线；第一张叠加「示例书目」胶囊。
- 卡下信息：书名、作者、`卷数 · 书源`、状态圆点 + 文案；鼠标悬停整卡上浮 4px、封面放大 1.2%，标题转紫。
- 「探索更多 →」跳转搜索页。

### 3.6 最近入库
- 表头 `#F8F7FC` 圆角条，四列 `1fr / 92 / 74 / 96`，与参考图列宽一致。
- 行：32×42 缩略封面（同一 CoverArt `mini` 模式，隐藏文字避免挤压）+ 书名 + 文件名 + 卷数 + 大小 + 完整性胶囊；行 hover 淡紫底。
- `<640px` 隐藏表头，行改为「封面/书名/文件名 + 卷·大小」两行结构，避免参考图桌面 4 列在手机上碎裂。

### 3.7 右栏
- **下载任务**（310×232）：标题 + 「查看全部 →」，2 条任务行（封面、书名、`下载中 · 第 x 卷 · 第 x 章`、进度条、66%/34%），进度条与百分比同参考图右对齐。
- **书库概览**（310×245）：2×2 统计块，浅紫图标圆角方块 + 数字 + 标签；底部注释「所有指标为本地模拟数据」。
- **最近活动**（310×284）：4 条，图标（下载/完成/失败）+ 文案 + 相对时间，垂直时间线式排列。

### 3.8 排版与细节
- 字号：页标题 28px/700，区段标题 15px/700（左侧 3×14px 紫色竖条），卡片标题 13px–13.5px，说明 10–11.5px，标签 9.5px。
- 卡片圆角 20px，内部块 10–14px，按钮 10–12px；阴影统一为低透明度大扩散，避免“脏边”。
- 毛玻璃只用于顶栏、侧栏底部卡、弹窗遮罩；未滥用模糊以免失焦。
- 动效时长 200–500ms，cubic-bezier 缓动；`prefers-reduced-motion: reduce` 时关闭位移动画。

## 4. 与参考图的差异及取舍

| 差异 | 原因 | 处理 |
| --- | --- | --- |
| 导航多出「自动追更 / 统计分析」 | 需求明确要求这两个入口 | 保持同一导航样式，纵向间距略压缩；均实现独立页面 |
| Hero 多出热门关键词 | 需求要求「热门搜索关键词」 | 放在提示行右侧，不改变搜索框与插画位置 |
| 顶栏/页面多处 Mock 标签 | 需求要求 Mock 必须可辨识 | 统一为琥珀色胶囊与浅紫说明条，融入设计语言 |
| 插画、封面非原图位图 | 原图无法直接提取可用素材，禁止整图截图 | 以参考图配色/构图原创 SVG 重绘；无外链、无拉伸、加载失败风险为 0 |
| 精选封面卡起点低 10px | 卡片头部留白与字体行高差异 | 已在 ±10px 内，整体卡片底边与参考图对齐 |
| 最近入库卡片低 3px | 精选卡高度 +1 与间距取整 | 可接受，未为 3px 破坏其他对齐 |
| 中文字形宽度差异 | Linux 截图回退 Noto Sans CJK | macOS/Windows 下更接近参考图的 PingFang/雅黑 |
| 参考图侧栏在 1050px 处结束 | 设计稿视口高约 1050，侧栏为 100vh | 实现同为 100vh 固定侧栏；整页截图表现一致 |

## 5. 迭代修复记录（截图对比驱动）

1. Hero 高度 247 → 289，四入口 `mt 42 → 18`，主内容 `mt 32`，与参考图纵向节奏对齐。
2. 精选/最近卡片重排：头部内边距、封面比例（试过 0.7，最终回到 3/4）、行高 `py-[11px]`。
3. 右栏三卡宽度 310、间距 19、内部 padding 逐项校准（下载 232 / 概览 245 / 活动 284）。
4. 状态色修正：连载绿、完结紫（此前误用蓝色）。
5. 缩略封面启用 `mini` 模式，去掉 32px 宽封面里的书名，避免文字挤压。
6. 封面左上角 `LIGHT NOVEL / 01` 在窄卡下换行 → 加 `whitespace-nowrap` 并缩小字距。
7. Hero 插画右侧书卡被裁切 → 扩大 viewBox 至 `-28 -18 462 306`，整体缩放 0.91，双卡完整可见。
8. 统计页柱状图不可见 → 固定 150px 柱槽 + 百分比高度，最低 6% 保证可见。
9. 详情页 / 自动追更页网格被拉伸出现大块空白 → `items-start`。
10. 书库统计「13.7 MB」重复单位 → 去掉 `占用空间 / MB` 的重复后缀。
11. 书源成功率数字与进度条挤在一行 → 数字上、进度条下。
12. 移动端「最近入库」表格错位 → 隐藏表头 + 两行卡片式行布局（见 3.6）。

## 6. 结论

- 布局骨架、区域比例、右栏结构、卡片排列、配色与字体层级均与参考图一致，关键区块坐标偏差 ≤3px（封面卡起点 +10px）。
- 参考图中的每个功能区域都由真实组件实现：导航、搜索框、按钮、封面卡、进度条、统计块、表格、活动列表、Toast、Modal 均可交互。
- 参考图之外新增的页面（搜索、详情、任务、书库、书源、自动追更、统计、设置）复用同一套设计变量，视觉语言统一；未实现能力仅做明确标注的占位。
